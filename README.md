# K-Cathedral Metaverse v5.0

한국 전통 성당 분위기의 브라우저 기반 3D 멀티플레이 공동체 프로토타입입니다. PC와 iPhone 브라우저에서 접속할 수 있습니다.

## v5.0 주요 기능
- 기존 성전, 야외 정원, 실시간 아바타 이동, 채팅, 기도 초 봉헌 유지
- 성모 기도실과 지하 묵상실 공간 추가
- 공간 이동 패널로 중앙 성전 / 성모 기도실 / 지하 묵상실 / 야외 정원 이동
- 최초 가입 계정을 관리자 역할로 지정(기존 데이터에 관리자가 없으면 첫 계정을 관리자로 승격)
- 관리자 대시보드: 접속자, 가입 회원, 봉헌 초, 기도 기록 확인 및 회원 관리자 권한 부여/해제
- 공동 미사 시작/종료 권한을 관리자에게 제한
- 아바타 의상 색상 저장

## 실행 방법
1. Node.js 20 이상 설치
2. 이 폴더에서 터미널 실행
3. `npm install`
4. `npm start`
5. PC에서 `http://localhost:3000` 접속
6. 같은 Wi-Fi의 iPhone은 PC의 내부 IP 주소를 확인해 `http://PC-IP:3000` 접속

## 최초 관리자
처음 가입한 계정이 관리자입니다. 기존 v4의 `data.json`을 복사해 업그레이드하는 경우, 기존 계정 중 첫 번째 계정이 관리자로 지정됩니다. 관리자 화면은 로그인 후 상단의 관리 버튼에서 엽니다.

## 배포 전 필수 보완 사항
현재는 개발용 프로토타입입니다. 공개 인터넷 서비스로 운영하기 전 HTTPS, 영구 데이터베이스(PostgreSQL 등), 세션 만료 및 영속화, 로그인 시도 제한, 이메일 인증/비밀번호 재설정, 관리자 감사 로그, 백업, 음성용 TURN 서버, 콘텐츠 신고/차단, 개인정보 처리방침이 필요합니다. 회원 데이터는 이 서버의 `data.json`에 저장되며 여러 서버 인스턴스를 사용하는 환경에는 적합하지 않습니다.

## 현재 구현 범위와 한계
아바타는 Three.js 기본 메시로 만든 관절형 캐릭터이며 실제 인물 수준의 포토리얼 모델이나 모션캡처가 아닙니다. 공동 미사는 상태 배너를 모든 접속자에게 공유하는 기능이며 실제 미사 영상 송출이나 종교의식 진행 시스템은 아닙니다. 음성 채팅은 WebRTC의 STUN 기반 베타로, 일부 네트워크에서는 별도 TURN 서버가 필요합니다.


## v5.1 캐릭터 업그레이드

- 외부 모델 파일 없이 Three.js로 생성되는 상세 관절형 아바타
- 얼굴: 눈 흰자·홍채·동공·눈썹·코·입·귀·머리카락 디테일
- 의상: 깃·앞섶·장식선·허리띠·십자가 펜던트·소매 장식·신발 디테일
- 애니메이션: 걷기·달리기·기도·앉기·무릎 꿇기·인사·손 흔들기, 호흡과 미세한 머리 움직임
- 모바일에서도 별도 GLB 다운로드 없이 동작하도록 절차적 메시 사용

참고: 이는 사실적인 게임풍의 절차적 캐릭터이며, 스캔 기반 포토리얼 인물 모델이나 모션캡처 데이터는 아닙니다. 실제 기기에서의 프레임 속도와 애니메이션 품질은 배포 환경에서 확인해야 합니다.

## K-Cathedral v7.0 — 온라인 미사 진행 도구
- 관리자 또는 사제 권한이 미사 시작/종료 가능
- 입당 예식, 말씀 전례, 강론, 보편 지향 기도, 마침 예식 단계 공유
- 진행자가 단계를 선택하면 모든 접속자 화면에 실시간 표시
- 관리자는 회원 권한을 사제(priest)로 지정하거나 해제 가능
- 기존 회원 데이터는 `data.json` 복사로 유지

### 사제 권한 지정
관리자 계정으로 로그인 → 관리 대시보드에서 회원 권한을 지정하세요. 사제 권한은 미사 시작/진행만 가능하며 관리자 대시보드에는 접근할 수 없습니다.

### 실행
```bash
npm install
npm start
```
참고: 이 기능은 온라인 공동체용 진행 안내입니다. 실제 전례 거행이나 성사 집전을 대체하지 않습니다.


## K-Cathedral v8.0 — 친구·개인 메시지·온라인 영상
- 회원 간 친구 요청, 수락 및 거절

- 영상 주소는 YouTube 영상 ID 형식만 허용하고 youtube-nocookie 임베드로 표시
- 기존 온라인 미사 진행 순서와 커뮤니티 기능 유지

### 주의

- 개인 메시지는 현재 `data.json`에 저장하는 단일 서버 프로토타입입니다. 공개 서비스에서는 PostgreSQL, HTTPS, 접근 로그·신고·차단 정책 등을 추가하세요.

### 실행

### iPhone에서 접속하기
1. 서버를 외부에서 접속 가능한 HTTPS 주소로 배포합니다. (예: Render, Railway, VPS 등)
2. iPhone에서 Safari로 배포된 `https://...` 주소를 엽니다.
3. Safari 공유 버튼을 누르고 **홈 화면에 추가**를 선택합니다.
4. 홈 화면의 K-Cathedral 아이콘으로 실행합니다.

주의: `localhost`는 iPhone에서 PC의 서버를 뜻하지 않습니다. 같은 Wi-Fi에서만 시험하려면 PC의 내부 IP 주소와 포트를 사용하고, PC 방화벽에서 해당 포트를 허용해야 합니다. 외부 어디서나 접속하려면 공개 배포와 HTTPS가 필요합니다. HTTPS가 아니면 카메라/마이크, 서비스 워커, 푸시 알림 등 일부 기능이 제한됩니다.

### Render 배포
1. 이 프로젝트를 GitHub 저장소에 업로드합니다.
2. Render에서 New > Blueprint를 선택하고 GitHub 저장소를 연결합니다.
3. `render.yaml` 설정을 확인하고 배포합니다.
4. 배포 완료 후 Render가 제공하는 HTTPS 주소를 아이폰 Safari에서 엽니다.
5. Safari 공유 메뉴에서 홈 화면에 추가합니다.

주의: `render.yaml`은 `starter` 유료 웹 서비스와 1GB 영구 디스크를 설정합니다. Render의 무료 서비스는 영구 디스크를 제공하지 않으므로 회원 데이터/사진 보존을 위해 무료 플랜으로 변경하지 마세요. 실제 요금은 배포 전 Render 대시보드에서 확인하세요.
